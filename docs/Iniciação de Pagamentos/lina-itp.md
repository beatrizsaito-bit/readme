> 📘 A quem é destinado este produto
>
> Esta seção é direcionada aos participantes indiretos do Open Finance Brasil que desejam aproveitar a praticidade das jornadas de iniciação de pagamentos no ecossistema Open Finance. Para os participantes diretos que preferem operar com licenças, autorizações, canais e experiências de usuário próprios, oferecemos uma solução de iniciação de pagamentos no nível de infraestrutura. Essa solução é completa, atendendo a todos os requisitos de segurança e funcionalidade necessários para operar como uma iniciadora de transações de pagamento.

O Portal de Iniciação foi projetado para simplificar o processo de iniciação de pagamentos,\
reduzindo significativamente o tempo e os recursos necessários para que as empresas possam oferecer\
a seus clientes uma experiência de pagamento moderna e eficiente.

## Integrações e interfaces

O produto de iniciação de pagamento da Lina ITP é composto por 4 diferentes camadas/interfaces:

### APIs

APIs autenticadas disponíveis na internet para integração com as instituições detentora de conta Estas APIs são utilizadas para a integração entre serviços para o usuário final e a finalização do pagamento no ecossistema do Open Finance Brasil. Com estas APIs, é possível ter controle total sobre a Jornada de Consentimento e a realização do pagamento nas instituições financeiras brasileiras.

### HPP (Hosted Payment Page)

Página de dados hospedada na plataforma da Lina, whitelabel, que já possui incorpora todas as interações necessárias para a jornada de iniciação de pagamento. Esta página pode ser customizada para adequar a Marca do parceiro, conduzindo a Jornada de Consentimento por conta própria.

### EPP (Embedded Payment Page)

Página de dados embeddada na aplicação dos nossos clientes utilizando os SDKs Lina. Os SDKs Lina promovem flexibilidade para a integração e utilização das funcionalidades de iniciação de pagamento. Desta forma, basta importar os SDKs nas aplicações dos parceiros e seguir os fluxos de integração definidos.
