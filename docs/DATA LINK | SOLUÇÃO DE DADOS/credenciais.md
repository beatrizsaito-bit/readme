Para criar as credenciais de API, entre na área de desenvolvedores do Data Manager e configure uma nova aplicação. Você poderá criar múltiplos **client IDs**, caso seja necessário. 

![](https://files.readme.io/cae4971527babf7af5fc05b04215145c412e7e410b050543a3da513c577d7186-image.png)

Posteriormente selecione a aplicação e baixe as variáveis de ambiente para importar diretamente no seu postman. Você também pode fazer o download da collection com todas as APIs já mapeadas.   

***

# Ambiente de Homologação

Você pode alternar entre os dados de **Homologação** e **Produção** de forma facilitada. Ao alterar de ambiente, as aplicações e credenciais também mudam.

![](https://files.readme.io/24daf1955580fda6a195fc2d76c28d74fa57e86cd87d1751ee4f4bbf9f562383-image.png)

<Callout icon="❗️">
  Confira se você está utilizando as credenciais do ambiente correto
</Callout>
